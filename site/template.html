Install

Install in four steps

You do not install Java, Minecraft, NeoForge or any mods yourself. The launcher does it.

  1. Unzip it

    Open your Downloads folder, right-click ChristmasCraft-Launcher.zip and choose Extract All. Click Browse, pick Documents, then Extract. A new folder opens.

    Don't just double-click the zip: that only shows what's inside, and the launcher won't run from there.

    Not Program Files, and not a OneDrive folder.

  2. Start the launcher

    In the new ChristmasCraft-Launcher folder, double-click prismlauncher.exe (it may show as just prismlauncher, with a blue cube icon).

    If Windows says it protected your PC, click More info, then Run anyway.

  3. Sign in

    Sign in with your Microsoft account when it asks.

  4. Press Play

    Double-click Christmas Craft.

    The first start downloads Java, Minecraft, NeoForge and {{mod_count}} mods: about 2 GB. Give it 5 to 15 minutes. A small window shows the progress.

You need

  • Windows.
  • A Microsoft account that owns Minecraft: Java Edition.
  • About 4 GB of free disk.

The download link always gives the current launcher. You only need it once.

Updates

Every time you press Play, the launcher checks for updates and installs them before the game starts. You never download the zip again.

Playing together

Everyone must be on the same version, so everyone presses Play first. If in doubt, close the game and press Play again.

  1. Start Christmas Craft and click Multiplayer.
  2. Click Add Server and enter the address posted in the Discord.
  3. Click Done, then join.

Voice chat: Simple Voice Chat is in the pack. Press V in game to set it up.

Help

If something goes wrong

Windows says it protected your PC

Click More info, then Run anyway. Some browsers also warn about the zip: choose to keep it.

Odd errors, or nothing saves

The folder is probably inside OneDrive or Program Files, or the launcher was opened from inside the zip. Extract the zip to Documents and open prismlauncher.exe from there.

The first start is slow

That is the 2 GB download. Give it 5 to 15 minutes.

A window says a download failed

Close it and press Play again. It carries on where it stopped.

"Incompatible client" when joining

You are on a different version. Close the game and press Play in the launcher so it updates. The friend you are joining does the same.

Low frame rate

Shaders are on by default. Turn them off in Options, Video Settings, Shader Packs.

PC with only 8 GB of memory

Turn the shaders off. In the launcher, right-click Christmas Craft, then Edit, Settings, Memory, and set the maximum to 5000.

Still stuck? Ask in the Discord. Say what you clicked and what you saw, and attach a screenshot if you can.
